# LapLab 短视频

## 开始前
本技能随完整仓库使用，仓库根目录是本技能目录的 ../../..。先读根目录 `AGENTS.md`、`docs/BRAND.md`、`docs/CREATIVE-WORKFLOW.md`；按下文加载场景资料。所有仓库相对路径均从根目录解析。若技能被单独复制且找不到这些资料，请用户提供仓库位置，不猜测品牌或素材。

## 工作方式
- 读取 `docs/VIDEO.md`、`docs/ASSETS.md`、`src/Root.tsx`、`src/PortraitFilm.tsx`、`src/LogoScene.tsx` 和 `src/brand.ts`；先查看已有 MP4 的关键帧及本次照片。
- 根据本次主题确认时长、画幅、照片和音乐段落。默认参考现有 9:16、1080×1920、30 fps；18 秒是已有样片长度，不是新活动的强制长度。
- 简报中记录镜头顺序、每段时长、中文主句、英文小字与人物避让位置。不能机械套用旧照片的 y 坐标。每次只出现一条信息，组合 Logo 与口号分别出现；Logo 卡不追加密集介绍。
- 优先新增独立合成或主题组件，再注册到 `src/Root.tsx`，保留已批准样片。轻微修改是否直接改已有合成依本次任务决定。动画使用 Remotion 帧驱动；时长、帧数和 composition 注册保持一致。
- 普通镜头可参考 0.4–0.8 秒，双语短句至少参考 1.4 秒且以实际读完为准，长句应简化或延长。不使用白屏频闪。
- 用用户指定原曲；若未指定，沿用现有样片音乐并说明。检查摘录起点加时长不超过音源；不擅自变速/变调。歌词文件不是逐字转写，未经核对不能当同步歌词字幕。

## 生成与验收
依赖未准备时在仓库根目录运行 `npm ci`；已有可用依赖无需重复安装。运行 `npm run assets:check`、`npm run typecheck`，然后用实际注册的合成 ID 渲染：

```sh
npx remotion render <合成ID> out/<主题>/video/film.mp4
```

占位符须换成实际值；原有样片可用 `npm run render:portrait`。需要指定浏览器时使用当前环境存在的 Chrome 路径，不写死维护者电脑路径。

交付 MP4、可编辑合成、使用的音乐片段和时间轴说明；记录实际帧率、尺寸、时长。查看首尾帧、全部文字镜头和新照片，听取配乐进出点并完整解码检查损坏。依赖或浏览器缺失导致未渲染时如实说明，不把源码或静帧称为完成的视频。不自动上传社媒。
