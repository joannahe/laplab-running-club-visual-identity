# LapLab 主题主视觉

## 开始前
本技能随完整仓库使用，仓库根目录是本技能目录的 ../../..。先读根目录 `AGENTS.md`、`docs/BRAND.md`、`docs/CREATIVE-WORKFLOW.md`；按下文加载场景资料。所有仓库相对路径均从根目录解析。若技能被单独复制且找不到这些资料，请用户提供仓库位置，不猜测品牌或素材。

## 工作方式
- 读取 `docs/ASSETS.md`；查看 `visual/方案封面.jpg` 和完整视觉 PDF 中与需求相关的页面。使用能读取图像或 PDF 的工具实际查看，而不只读文件名。
- 明确活动主题、对象、投放场景与主信息。用 `templates/creative-brief.md` 整理简报；未知活动信息标为待确认。
- 在既定品牌内给出适合当前活动的一套主题：中文主句与英文小字、主次层级、照片选择、留白、构图、尺寸和场景变化。用户只要单张时直接做单张，不扩大为全套。
- 先完成可编辑主视觉与预览，再根据请求延展。将主题共性写入交付目录的 `theme.md`，供其他场景技能继续使用；其中记录主句、译文、素材路径、颜色用途、字体、构图与各尺寸的调整原则。
- 主题可以是夜跑、速度课、轻松跑或周年活动；这些是内容主题，不是新增品牌配色。不得将示例名称、日期或训练计划当成已确认事实。

## 交付与验收
交付简报、可编辑主视觉、导出图、`theme.md` 和简短使用说明。检查 Logo 原稿组合、中英层级、手机/远观可读性、人脸避让与不同裁切。只生成用户请求的尺寸，记录实际输出规格；未执行渲染的文件不称为已验收成品。
