# LapLab 社媒图文

## 开始前
本技能随完整仓库使用，仓库根目录是本技能目录的 ../../..。先读根目录 `AGENTS.md`、`docs/BRAND.md`、`docs/CREATIVE-WORKFLOW.md`；按下文加载场景资料。所有仓库相对路径均从根目录解析。若技能被单独复制且找不到这些资料，请用户提供仓库位置，不猜测品牌或素材。

## 工作方式
- 读取 `docs/SOCIAL.md`、`docs/SOCIAL-EDITING.md` 和 `docs/ASSETS.md`。根据用途查看 `materials/social/zh/`、`materials/social/en/` 的对应 PNG；信息页优先参考 2、4、6 页，主页类参考 `materials/applications/主页背景.png` 与 `主页预览.png`。
- 沿用已有主题简报或确定本次主题、语言、页数与真实活动信息。用户未要求双语两套时不默认翻倍生成；需要英文时独立排版，不能在中文图上覆盖翻译。
- 中文轮播保持纯中文（原 Logo 除外）；英文正文正常大小写和字重。整体 KV 的英文小注释规则不套用到中文轮播。
- 每页一个主信息；保持 V2 大字号，文案多时删减、拆页或用粉笔白浅底和炭黑字，不靠缩字硬塞。沿用电光训练色系，不全页铺电光绿。
- 默认沿用已有轮播的 1080×1440；其他尺寸按用户用途调整。主页背景体现「LapLab 跑团」和「严肃训练，轻松相处」。主页预览中的粉丝数等示例不当作真实数据。
- 优先复制 `social/zh.json` 或 `social/en.json`，编辑内容后用 `npm run social:render -- --data <配置路径> --out out/<主题>/social` 导出。不依赖生图模型；布局变化编辑 `src/social/SocialCard.tsx`，使用原始组合标。新内容中的数字要与 easy/speed 模板装饰数字一致；模板未满足需求时再新增布局。

## 交付与验收
运行 `npm run typecheck` 并实际导出，检查文字溢出报错。按需要输出 `zh/` 或 `en/`、JSON 与可编辑版式源文件、各页文案及用途说明；多页时附总览。以手机尺寸逐页查看标题、正文、换行、边缘裁切和标识；检查日期/地点/配速来自简报。只做预览时明确标注，别将示例活动当成可直接发布的信息。
