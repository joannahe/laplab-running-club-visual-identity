# LapLab 线下物料

## 开始前
本技能随完整仓库使用，仓库根目录是本技能目录的 ../../..。先读根目录 `AGENTS.md`、`docs/BRAND.md`、`docs/CREATIVE-WORKFLOW.md`；按下文加载场景资料。所有仓库相对路径均从根目录解析。若技能被单独复制且找不到这些资料，请用户提供仓库位置，不猜测品牌或素材。

## 工作方式
- 读取 `docs/ASSETS.md`，查看 `materials/applications/` 中对应物料和视觉 PDF 的相关页面。已有图片是效果参考，不是可直接送印的分层源稿。
- 如果已有主题目录，沿用其中 `brief.md` 和 `theme.md`。否则简要确定物料种类、用途、主文案和是否仅做概念稿。
- 概念设计不强求具体横幅尺寸；选合适展示比例并标注「概念稿／尺寸待定」。不得因缺少印厂参数阻塞概念设计。
- 实际生产文件需要用户或供应商提供成品尺寸、出血、工艺、材质、颜色要求与刀模（若适用）。缺失时仍可完成可评审概念稿，但不能宣称已经可以送印；不虚构 CMYK 或专色匹配。
- 横幅、衣服背面等额外身份文字保留「LapLab 跑团」，整体 KV 按需配英文小字。Logo 使用原始组合，不重打字替代，不从效果图中抠出低清标识。
- 以工具实际支持的可编辑格式构建版式，例如 SVG、HTML/CSS 或设计软件源文件。保留原始 Logo；若供应商要求矢量而仓库只有位图，明确需要原始矢量，不描摹冒充。

## 交付与验收
概念阶段交付可编辑源文件、平面设计预览、适用时的物料效果预览及规格说明。生产阶段另交供应商要求的文件，并记录真实尺寸、出血、字体处理、位图有效分辨率及未确认项。实看导出图，检查远观可读性、拼接/缝线/裁切位置与 Logo 完整性；不能把低分辨率效果图称为生产稿。
