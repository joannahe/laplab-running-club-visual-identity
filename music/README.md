## Agent 选曲与剪辑规则

1. 用户指定曲目优先；否则先识别视频场景与情绪，再查 catalog.json，推荐曲名、版本和理由。
2. 同名不同版本都保留；未经试听不对版本优劣、实际快慢或高潮位置作判断。
3. 优先使用 WAV 剪辑；M4A 内为 Opus，若渲染器不兼容则另建派生格式，不覆盖原曲。音频均为 48 kHz 双声道。
4. 逐拍剪辑前分析实际节拍；交付记录源文件、截取起止秒、音量和淡入淡出，不擅自变速变调。
5. 歌词是创作稿或音频内嵌文本，不是已校准字幕。先核对实际演唱、段落重复与时间码；有人声时避免密集旁白争抢。
6. Electric Session 提示词保留用户原文，其中写有 Mandarin lead vocal；LapLab 的对应歌词为英文。不要根据提示词单独断言成品语言。
