# LapLab 品牌规范

## 主旨
LapLab 是上海张江的独立跑步社群，成立于 2024 年 12 月。
Lap：一圈圈训练、重复与积累。Lab：实验、探索与创新。
核心口号：**严肃训练，轻松相处。 / Serious training. Easy company.**
尊重不同节奏和个人目标；专业训练与友好相处并存，不以他人成绩定义自己。

## 标识
原始双 L 闪电来自两个交叠的 L。闪电与原始 LAP/LAB 堆叠字标同步移动、缩放和出现，始终保持为一个组合，不重绘、不用字体仿造。
视频主标居中且足够大；不额外堆叠口号和说明。作为照片上的主视觉时，寻找空白区域，避开人脸。
横幅、衣服背面、主页背景等有额外身份文案时，使用「LapLab 跑团」，并按整体 KV 需要添加「LapLab Running Club」。Logo-only 视频卡不追加文字。

## 电光训练 / Electric Session（当前视频）
| Token | HEX | 用途 |
|---|---|---|
| Charcoal 炭黑 | #171A1D | 品牌底色、画面留白 |
| Chalk 粉笔白 | #F3F4ED | 中文主句、主要文字 |
| Electric lime 电光绿 | #D7FF3F | 英文注释、重点提示、点缀 |
| Cool grey 冷灰 | #A8B0AD | 次要信息 |

照片本身保留自然色，不把服装/肤色染成主题色。视频保留原始白色/灰白标识；社媒工程默认绿色闪电＋按背景选择黑/白字标，使用 public/logo/，见 [LOGOS.md](LOGOS.md)。
配色展示页（PDF 第 4 页）用中性浅灰 #E5E5E5，深色文字 #252525、色块细边 #B8B8B8，避免主题色与页面底色融合。其他页面不因此统一改灰。

## 字体
英文品牌标题建议 Barlow Condensed ExtraBold Italic；英文解释、正文和视频小字幕使用 Barlow Condensed Regular。允许重点标题强调，禁止所有英文都大写加粗。
中文沿用原方案字体：当前渲染环境使用 Arial Unicode MS；项目保留 PingFang SC / Noto Sans CJK SC / sans-serif 作为系统回退。中文字体不随源码分发。跨平台替换后需重新检查换行、字宽和视觉密度。
字体不能替代原始 Logo。Barlow 字体与 OFL 授权在 `public/fonts/`，必须一起保留。

## 语言与使用场景
- 整体视觉方案、KV、视频：中文为主，英文小字解释。
- 中文社媒图文：不添加英文解释；英文版独立制作。
- 社媒沿用 V2 大字效果；信息多的页面优先浅底，保持字号清楚。
- 视频句库（建议分开出现）：
  - 严肃训练。 / Serious training.
  - 轻松相处。 / Easy company.
  - 各有节奏。 / Your rhythm.
  - 一起刷圈。 / Our laps.
- 英文是口号对应文案，不是歌词逐字字幕。不要根据音乐正在唱什么自动更改品牌文案。

新增已确认的帽背版标识为 LAP/LAB＋跑团＋Running Club，不含闪电；可用于新版视频片尾，与下方中英文口号同屏。此用途是组合标与口号分场原则的明确例外；详见 VIDEO.md、LOGOS.md。
